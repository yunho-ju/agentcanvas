# 모델 없이 지시문을 표준 구조로 옮기면 무엇이 되는가 — 두 언어가 함께 읽는 케이스

`cases.json`은 contracts(Python)의 `scaffold_skill`과 studio(TS)의 `scaffoldSkill`이
**같은 입력에서 같은 글자**를 내는지 맞춰 보는 자리다. 부를 모델이 없을 때 서버가
돌려주는 틀 초안과 화면이 그리는 틀 초안이 갈리면, 승인한 것과 저장된 것이 달라진다.

한 케이스의 뜻:

| 칸 | 뜻 |
|---|---|
| `name` | 케이스 이름 (사람이 읽는다) |
| `skillName` | 사람이 적은 skill 이름 |
| `description` | 사람이 적은 '언제 쓰나요' 한 줄 |
| `instruction` | 그 단계에 적혀 있던 지시문 |
| `expect` | 나와야 하는 SKILL.md 전문 (줄 목록 — 파일이 아니라 여기 그대로 적는다) |

`expect`는 두 쪽 모두 우리 파서(`parse_skill_markdown`)로 읽었을 때 **issue 없이**
skill이 되어야 한다 — 우리가 지은 틀이 우리 규칙을 통과하지 못하면 그 규칙은 규칙이 아니다.
모르는 것은 지어내지 않는다: 사람이 적지 않은 절은 만들지 않는다.
