# 도구 결과를 모델에게 넣기 전에 감싸는 규칙 — 함께 읽는 케이스

`cases.json`은 engine(Python)의 `tool_result_fence`가 도구 결과를 어떤 모양으로 모델에게
넘기는지 못 박아 둔 자리다. 도구가 돌려준 글이 지시문 행세를 하지 못하게 하는 최소 방어이고
(설계 `docs/AGENT_PATTERNS_DESIGN.md` D9), 완전한 방어는 아니다 — 감싸는 글자 자체를 흉내
내는 결과까지 막지는 못한다.

규칙은 engine의 것이 원본이다:

- 다듬는다: 줄바꿈(`\n`)과 탭(`\t`)만 남기고 다른 제어문자는 걷어 낸다.
- 자른다: 다듬은 뒤의 글자 수가 `max_chars`(기본 8000)를 넘으면 거기서 자르고 끝에
  `…(cut)`을 붙인다 — 조용히 자르지 않는다.
- 감싼다: `<<tool_result name=…>>` 줄과 `<</tool_result>>` 줄 사이에 넣는다.

한 케이스의 뜻:

| 칸 | 뜻 |
|---|---|
| `name` | 이 케이스가 무엇을 보는지 |
| `text` | 도구가 돌려준 글 (결과 처리는 이미 끝난 뒤다) |
| `tool` | 그 도구의 이름 — 감싸는 줄에 적힌다 |
| `max_chars` | 이 케이스의 상한 (없으면 기본값) |
| `expected` | 감싼 결과 — 글자 하나까지 그대로 맞아야 한다 |
